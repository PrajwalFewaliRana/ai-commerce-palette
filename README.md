# **Aura Design System**

Create a complete Design System for an AI-powered Multi-Vendor E-Commerce Platform.

Generate a reusable design language using React, Tailwind CSS, TypeScript, shadcn/ui, and Lucide icons.

Create:

 Color palette (Primary, Secondary, Success, Warning, Error)

 Typography scale (H1–H6, Body, Caption)

 Spacing system (4px, 8px, 16px, 24px, 32px...)

 Border radius

 Shadows

 Button variants

 Input components

 Search bars

 AI search component

 Product cards

 Category cards

 Dashboard cards

 Tables

 Modals

 Drawers

 Navigation

 Sidebar

 Breadcrumbs

 Pagination

 Loading Skeletons

 Empty States

 Toast Notifications

 Status Badges

 Charts

 Responsive breakpoints

 Dark mode

Every future page must reuse these components.
